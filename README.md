# 🌍 Rural Internship E-Poster: Reelief Foundation

An academic and professional E-Poster designed entirely from scratch using **HTML5** and **CSS3**. This project documents my public health and digital outreach internship with the **Reelief Foundation** (Bhosari, Pune) for the 2025-26 session. 

Instead of relying on graphic design software, I chose to build this programmatically to leverage web technologies, ensuring pixel-perfect grid alignment, scalable typography, and easy version control.

## 🔗 Live Preview
Check out the rendered E-Poster directly in your browser:  
👉 **[View E-Poster on GitHub Pages](https://liambrooks-lab.github.io/Rural_Internship_poster/)**

## 🚀 Key Highlights
* **CSS Grid & Flexbox:** Architected a modular 2-column A3 portrait layout.
* **Print-Optimized:** Configured specifically for browser-to-PDF rendering with zero margin bleeding and exact background graphic retention.
* **Content:** Showcases grassroots initiatives including HIV/AIDS Migrant health camps, FSW project documentation, and custom web-based scheduling deployments.

## 🛠️ Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (Variables, Grid, Flexbox)
* **Design Pattern:** A3 Print-Ready Ratio (1122px x 1587px)

## 💻 How to Use & Export
1. Clone this repository:
   ```bash
   git clone https://github.com/liambrooks-lab/Rural_Internship_poster.git
   ```
2. Open the `poster.html` file in any Chromium-based browser (Chrome, Edge, Brave).
3. To generate the high-resolution poster:
   * Press `Ctrl + P` (or `Cmd + P`).
   * Set destination to **Save as PDF**.
   * Under **More Settings**: Set Paper size to `A3`, Margins to `None`, and check `Background graphics`.
   * Click **Save**.
